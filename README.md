# Eye Disease Data Analytics Portfolio Project

## Overview
This project demonstrates an end-to-end health informatics workflow analyzing eye disease classification data (Cataract, Diabetic Retinopathy, Glaucoma, and Normal). It showcases data aggregation and clinical data visualization skills tailored for optometry and healthcare research.

## Tech Stack & Tools
* **SQL:** Used for data extraction, transformation, and aggregation.
* **Tableau:** Used for building a clean clinical dashboard to visualize disease prevalence.
* **GitHub:** Version control and portfolio hosting.

## Repository Contents
* `eye_disease_analysis.sql`: Core aggregation script.
* `eye_disease_summary.csv`: Processed summary dataset.
* `eye_disease_dashboard.twbx`: Interactive Tableau visualization workbook.
